Нужно показать мне, сколько токенов потратила каждая роль. Хуки и `/budget` следят только за `architect` и `data-engineer`; остальные роли (в основном `backend-dev`, `qa-engineer`, `reviewer`) считает этот скилл.

Аргументы: $ARGUMENTS

## Как
1. Запусти (только чтение, транскрипты в `~/.claude/projects/*/*/subagents/`):
   `uv run --no-project python .claude/skills/usage-by-role/usage_by_role.py --since <дата начала этапа или недели>`
   Без `--since` считаются все запуски. Для разбора в JSON добавь `--json`.
2. Недельный процент лимита — `mcp__ccd_session_mgmt__get_usage` (загрузи через ToolSearch, если не загружен). Точный процент по ролям получить нельзя, поэтому доли считаются как output + cache creation: cache read дёшев и в долю не входит.
3. Покажи мне короткую таблицу: роль, запусков, output, cache creation, доля. Отметь строку `unknown` (запуски, где роль не распознана по промту) и сколько в ней.
4. Если одна роль съела больше трети, предложи, что сократить: меньше параллельных запусков, один прогон тестов вместо двух, более узкое задание.

## Ограничения
- Транскрипты читаются с диска текущей машины; сессии, которых тут нет, не видны.
- Это оценка расхода по полям `usage` ответов модели, а не счёт по тарифу.
- Скрипт не меняет файлов и не обращается в сеть.
