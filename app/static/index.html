Mars Rover API

An open, unofficial replacement for the archived Mars Rover Photos API.

This is an independent community project. It is not affiliated with, endorsed by or operated by NASA or JPL. Photos and metadata come from the public raw image feeds and archives published by NASA/JPL.

Moving from the old API

Replace the host and keep the rest of the URL. No API key is needed; an api_key parameter is accepted and ignored.

https://api.nasa.gov/mars-photos/...  →  $origin/mars-photos/...

The same API is also served under $origin/api/v1/....

Differences from the old API

  • Rate limit per client IP, no key: 60 requests per minute and 2000 per hour. Over the limit you get 429 with a Retry-After header.
  • Spirit and Opportunity: img_src points to reduced-resolution JPEG previews from the NASA PDS archive (the old MER gallery is gone).
  • Curiosity up to sol 4102: only full frames are served (no thumbnails or subframes).
  • Photo ids are new; ids from the old API do not carry over.

Examples

v1, compatible with the old API:

curl "$origin/mars-photos/api/v1/rovers/curiosity/photos?sol=1000&camera=fhaz"
curl "$origin/mars-photos/api/v1/rovers/perseverance/latest_photos"
curl "$origin/mars-photos/api/v1/manifests/opportunity"

v2, the new API:

curl "$origin/api/v2/rovers"
curl "$origin/api/v2/rovers/perseverance/photos?sol=100&per_page=50"

Interactive documentation of every endpoint: /docs.

Prefer a web interface? Browse the photos at the Sol Index.
