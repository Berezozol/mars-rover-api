Редакция 1 (2026-11-26, HEAD `20068b4`). Основа: разбор страницы `/rovers/{rover}/sols/{sol}/conditions` скиллом Impeccable (`critique` + `audit`, 2026-11-26: дизайн 27/40, техника 16/20); решение владельца 2026-11-26 — брать в работу P1 и P2.

## 1. Факты

- Курсор: `frontend/src/pages/SolReport.tsx:239-261` и `:480-506` — `<output>` пишет «none selected», а ползунок стоит на 13:00.
- Полоса часа: `frontend/src/solreport.css:56-101`; на 375×812 шапка 81 px + полоса 120 px (три строки).
- Шапка страницы: блок фактов из 7 строк `SolReport.tsx:325-379`; суточные `min`/`max`/`mean` есть в ответе `/weather/{sol}` (поля WeatherSol), суточная доза — в `/radiation/{sol}` (`dose_e_ugy_day.mean`).
- Пометки качества: `frontend/src/components/HourChart.tsx:131-134`, источник — `frontend/src/lib/solReport.ts:136-137`; пояснения есть в `frontend/src/lib/weather.ts:42`.
- Таблица часов: `SolReport.tsx:585-631`, только средние погоды.
- Касание: `HourChart.tsx:158-166` (`onPointerMove` только для мыши или нажатой кнопки), `touch-action: pan-y` в `solreport.css:148-151`.
- Заголовки: h1 (`SolReport.tsx:305`), затем h3 графиков (`HourChart.tsx:129`) без h2.

## 3. Решения

1. Сброс курсора — отдельная кнопка, а не «уход мыши с графика»: на касании ухода нет.
2. На узком экране закреплённая полоса — подпись «Hour», ползунок, вывод и кнопка сброса в одну строку; «Shade night» переезжает в строку над графиками (не закреплена).
3. Сводка строится только из полей ответа, без новых вычислений; округление — как в графиках.
4. Пояснения пометок — видимым текстом; `title` остаётся как дополнение.
5. Протяжка пальцем: захват указателя на `pointerdown` касанием, движение по горизонтали двигает курсор, `touch-action: pan-y` сохраняется.
