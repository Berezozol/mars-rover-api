## 3. Решения
- Правило выброса (AC-4…AC-7): для значений ряда в диапазоне (не меньше 20 точек) берётся `m` — медиана. Выбросы — значения больше `3 × m`. (Первая редакция с `2 ×` 99,5-го перцентиля не срабатывала на рядах короче ≈ 200 точек — всплеск сам становился перцентилем; по всей истории дозы E выше `3 × m` только сол 4190.) Ряд графика дозы — значения E и B вместе, в подписи — наибольшее из них по солу. Если выбросы есть и выбран режим `auto` или `fit` (в том числе `auto` на длинном диапазоне, где низ шкалы — 0), шкала строится по значениям без выбросов (как раньше по всем), выбросы рисуются на верхнем крае. Иначе — как до правки.
- Подпись: один выброс — `Sol N: X µGy/day, off scale`; несколько — `K sols off scale, highest sol N: X µGy/day`. Значение — как в таблице (`dose()`, `rate()`).
- Инспектор удаляется целиком; если `WeatherInspector.tsx` остаётся нужен только ради `FlagPill`, `FlagPill` переезжает в отдельный файл.
