# План по этапам

**Цель проекта:** открытая неофициальная замена архивированного Mars Rover Photos API. Старые клиенты переезжают сменой хоста (v1, `LEGACY-API.md`), новые получают более полный API v2. Фронтенд — после того как бэкенд и ручки готовы.

Каждый этап запускается командой `/stage <номер>`. Этап закрыт, когда выполнены все пункты «Готово, когда». Отметки `[x]` и журнал ведёт тимлид.

## Этап 9a. Полноразмерные снимки Spirit и Opportunity (конвертация на лету)
В архиве PDS у MER полноразмерные кадры есть только в формате `.img` (PDS3, обычно 1024×1024, 12 бит), браузер его не показывает; для просмотра есть лишь маленькие JPEG. Решение владельца (2026-11-18): конвертировать на лету, архив целиком не качать.
- [x] `/api/v2/photos/{id}/image?size=full` для MER: скачать `.img` из PDS по `source_link`, разобрать PDS3 (метка, растр, растяжение яркости 12 → 8 бит), отдать PNG/JPEG; превью (`small`) — по-прежнему JPEG архива
- [x] Кэш готовых картинок на диске с лимитом размера и вытеснением старых; ограничение параллельных конвертаций и частоты запросов к PDS; заголовки кэширования как у редиректа
- [x] v1: `img_src` — решено (владелец, 2026-11-19): остаётся превью PDS, без изменений; иначе каждая страница v1 запускала бы десятки конвертаций. Полный кадр — только через v2 (JPEG q90, растяжение 0,5–99,5%, кэш 5 ГБ, 2 конвертации одновременно)

**Готово, когда:** полноразмерный снимок MER открывается в браузере, повторный запрос отдаётся из кэша, нагрузка на PDS ограничена.
