# План по этапам

**Цель проекта:** открытая неофициальная замена архивированного Mars Rover Photos API. Старые клиенты переезжают сменой хоста (v1, `LEGACY-API.md`), новые получают более полный API v2. Фронтенд — после того как бэкенд и ручки готовы.

Каждый этап запускается командой `/stage <номер>`. Этап закрыт, когда выполнены все пункты «Готово, когда». Отметки `[x]` и журнал ведёт тимлид.
