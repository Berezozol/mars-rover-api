# Миниатюры Curiosity (MSL) из фида JPL — сопоставление с кадрами (ADR-4А)

Дата: 2026-11-24. Исполнитель: `data-engineer`. Внешних запросов: **28** (список в конце). База `mars` — только чтение; история не загружалась.

## Вывод
Соответствие есть и оно однозначное **в направлении «кадр → миниатюра»**: ключ — `imageid` без буквы типа продукта (и без версии у MSSS). Миниатюры фида можно писать в `img_small`, **перезагружать историю кадров не нужно**: достаточно отдельно забрать только миниатюры (~730 тыс. записей) фильтром `extended=thumbnail::sample_type::eq` с `per_page=1000` — порядка **750–1 000 запросов** вместо ~7,6 тыс. страниц полной перезагрузки без фильтра.

## 1. Ключ сопоставления
`imageid` имеет два формата, тип продукта — одна буква в фиксированной позиции.

| Формат | Камеры | Пример кадр → миниатюра | Ключ |
|---|---|---|---|
| MSSS (`SSSS` + код камеры + 16 цифр + буква + 2 знака версии + `_DXXX`) | `MAST_LEFT/RIGHT`, `MAHLI`, `MARDI` | `4327MR1065450012201536E01_DXXX` → `…1536I01_DXXX` | первые 22 символа (`imageid[:22]`) |
| OPGS (`XXX_<sclk>EDR_<буква><…>`) | `NAV_*`, `FHAZ_*`, `RHAZ_*`, `CHEMCAM_RMI` | `NRB_847853302EDR_F1252490NCAM00354M_` → `…EDR_T1252490…` | `imageid` с маской позиции 17 |

Буквы (пары, найденные на выборке): MSSS `C00`, `D01–D03`, `E01–E0C` → `I01`; MAHLI `R00` → `T01`, `S00` → `U01`. OPGS `F`, `S`, `D`, `M` → `T`. Код камеры входит в ключ, поэтому камеру отдельно сверять не нужно.

- Миниатюр с одинаковым ключом — **0** из 3 123: у кадра не бывает двух миниатюр.
- Обратное не взаимно однозначно: на одну миниатюру MSSS приходится до 3 кадров одного снимка (`C00` + `E01`, иногда ещё `E03`/`D0x`): из 2 878 ключей кадров у 288 по 2 кадра, у 6 — по 3. Это один и тот же снимок в разных продуктах, общая миниатюра для них корректна.
- `date_taken` пары совпадает в 2 608 из 3 012 случаев; у кадров `C00` время на ~4 с меньше, чем у миниатюры — как ключ `date_taken` **не годится**. `sclk`, `subframe_rect`, `scale_factor` у MSSS — `null`; у OPGS `sclk` в имени и так есть.
- Правило имени даёт **точный URL** миниатюры: замена буквы (и версии на `01`) в `https_url` кадра совпала с `https_url` миниатюры в **3 012 из 3 012** пар (каталог и хост те же).
- Исключение — ChemCam RMI: у миниатюры другой `sclk` в имени (`CR0_398380679EDR_T…` при кадре `CR0_398380645EDR_F…`, +34), совпадает только `date_taken`; миниатюры RMI встретились лишь на соле 10.

## 3. Как выглядит миниатюра
| Файл | Пиксели | Байт |
|---|---|---|
| Mastcam L / R (сол 5073) | 192×144 | 1 525 / 1 253 |
| MAHLI `U01` (сол 5073) | 192×144 | 1 876 |
| MARDI (сол 4500) | 192×144 | 3 294 |
| Navcam `NRB_…T…` (сол 5073) | 64×64 | 2 646 |

- MSSS — 192×144, OPGS (Navcam/Hazcam) — **64×64** (`subframe_rect (1,1,64,64)`, `scale_factor 16`). 64 px мелко для карточки сетки, при растяжении будет мыло.
- Ответы `200 image/jpeg` с `mars.nasa.gov`. Старые записи (сол 100) ссылаются на `mars.jpl.nasa.gov` → `301` (так же, как у 354 653 наших `img_full`). Несуществующая миниатюра (предсказанный URL для кадра RMI) → **`403` text/html**, не 404.
- Охват кадра: миниатюра субкадра — это субкадр или весь детектор? `[не проверено]` (у Mastcam миниатюра всегда 4:3, а субкадры бывают другой формы). Перед внедрением посмотреть глазами несколько пар (`/ui-check`).

## 5. Рекомендация
Делать **способом Б** (если владелец хочет `img_small` у Curiosity):
1. `backend-dev`: в адаптере MSL — метод «миниатюры сола/пачки солов» (`…::eq`, `per_page=1000`), функция ключа (`imageid[:22]` для MSSS, маска позиции 17 для OPGS), запись `https_url` миниатюры в `img_small` только при найденной паре; ChemCam RMI не трогать. В `sync` — тот же шаг для синхронизируемых солов.
2. Добор истории — отдельной командой (`backfill-thumbnails` или флаг), пачками солов; запускает тимлид, ~1 тыс. запросов — внешние запросы, решает владелец.
3. Перед этим владельцу решить: 64×64 у Navcam/Hazcam годится для сетки или `img_small` ставить только MSSS (Mastcam, MAHLI, MARDI — это 51% кадров Curiosity в базе).
Способ В (правило без запросов) — только как запасной, с заглушкой `onerror` во фронтенде.
