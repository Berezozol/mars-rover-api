## 2. Что лежит в CAL_TIRS (SIS + метка + данные)

- `CAL_TIRS` содержит `GROUND_TEMP` и `GROUND_TEMP_UNCERTAINTY` — «TIRS Ground brightness temperature in Kelvin» (канал 8–14 мкм), а также `UPWARD_LW_IRRADIANCE` (6,5–30 мкм, Вт/м²), `AIR_TEMP` (температура самого TIRS, не атмосферы), `DOWNWARD_LW_IRRADIANCE`, `UPWARD_SW_IRRADIANCE` и те же флаги, что в `DER_TIRS`. Метод A возможен.
- В `DER_TIRS` столбца температуры грунта нет, но его метка говорит, что `UPWARD_LW_IRRADIANCE` дан «assuming Stefan-Boltzmann emission for the ground».
- Размер: сол 1 — 10,8 КБ (короткий сеанс, 90 строк в 15:xx LTST); обычный сол ≈ 5,5–5,9 МБ.
- DOI в SIS и метках не найден (SIS — Draft 01, DOI не содержит).

## 3. Результат сравнения методов (почасовые медианы LTST, фильтр: `ROVER_LOW_TILT=1`, колесо не в поле зрения)

Обозначения: A — `CAL_TIRS.GROUND_TEMP`; B1 — обращение интеграла Планка 6,5–30 мкм от `CAL_TIRS.UPWARD_LW` (ε = 1); S — наивный `(F/σ)^¼` от `DER_TIRS.UPWARD_LW`; B2 — то же обращение по полосе, применённое к `DER_TIRS`; Ta — медиана `ATS_LOCAL_TEMP1..3`.

| Сол | A макс / мин, К | S макс / мин, К | B1 макс / мин | B2 макс / мин | Ta макс / мин |
|---|---|---|---|---|---|
| 100 | 268,7 (13 ч) / 196,8 (05 ч) | 268,9 / 197,5 | 232,4 / 165,9 | 281,7 / 211,6 | 243,1 / 194,4 |
| 200 | 278,5 (13 ч) / 192,4 (05 ч) | 278,4 / 193,3 | 241,3 / 162,1 | 291,6 / 207,7 | 245,7 / 196,9 |
| 400 | 286,1 (12 ч) / 185,4 (05 ч) | 286,1 / 186,5 | 248,4 / 155,8 | 299,6 / 201,3 | 260,3 / 192,5 |

Выводы:
1. **S совпадает с A в пределах ≤ 1,1 К в каждый час солов 100, 200, 400** (в среднем ≈ 0,5 К, S чуть выше). То есть `DER_TIRS.UPWARD_LW_IRRADIANCE` — это не измеренный поток в полосе, а `σ·T_b⁴`, пересчитанный из яркостной температуры. Гипотеза спецификации «наивный Стефан — Больцман занижает из-за полосы 6,5–30 мкм» **не подтверждается**: полосная поправка здесь не нужна, а метод B1/B2 даёт заведомо неверные 156–300 К (B1 на 33–38 К холоднее A, B2 на 13 К теплее) — метод B отклоняется.
2. Сутки физичны: максимум 269–286 К около 12–13 ч LTST, минимум 185–197 К перед рассветом; днём грунт теплее воздуха на 25–35 К, ночью холоднее на 5–10 К. Сезонный рост амплитуды с солами 100 → 400 виден.
3. **Сол 1 — исключение**: A = 190,8 К, S = 200,0 К (расхождение 9 К) при воздухе 252,7 К в 15:xx LTST; физически грунт днём не может быть на 60 К холоднее воздуха. Сол 1 — короткий сеанс проверки прибора, использовать его для оценок нельзя. Наблюдавшиеся «201 К» — это именно значение `DER_TIRS` сола 1, а не ошибка метода.
4. Дополнительно: часы с чётными номерами имеют ≈ 2600–3700 строк, нечётные ≈ 270–1400 (чередование сеансов/покрытия); медианы устойчивы, но суточный максимум может приходиться на час без данных.

Приложенных машиночитаемых данных нет: Data Set S1–S3 (ASCII) на странице не проверялись [не проверено], по тексту S3 — список перекалибровок TIRS, S2 — модельные таблицы; в Data Availability сказано, что все данные для рисунков берутся из PDS (т.е. из тех же `CAL/DER_TIRS`, что у нас), а в репозитории USRA лежит только LWd.

**Ключевое подтверждение метода (разд. 3.1.2.2 статьи):** значения `DER_TIRS` LWu получены авторами так: яркостная температура `Tb_IR4` из `CAL` LWu по предполётным калибровкам, затем `LWu = σ·Tb⁴` (ε = 1, σ = 5,67·10⁻⁸). Наш `T = (LWu_DER/σ)^0,25` — точное обращение этой формулы, то есть воспроизводит их `Tg` по построению (подтверждает остаток ≤ 1,1 К к `CAL_TIRS.GROUND_TEMP`, найденный в п. 3). Ошибка ε = 1 по Mini-TES: до 3 % по LWu при 290 К и до 6 % при 180 К (≈ 0,75…1,5 % по T, то есть ≈ 2–3 К) — это неопределённость самой величины, а не нашего расчёта. Точность канала Tg: ±0,75 К.

Опубликованные числовые значения в тексте (рисунки 3c, 5 числами не даны; рендера PDF в среде нет, по картинкам не сравнивал):
- суточная амплитуда Tg ≈ 87 К на солах 181–199 и ≈ 56 К на солах 138–152 (разд. 4.2).

Наша оценка из локального `DER_TIRS` (скрипт `scripts/weather_ground_published.py`, суточная амплитуда = максимум − минимум почасовых медиан LTST, фильтр как выше):

| Солы | Опубликовано | Наше (среднее) | Отклонение |
|---|---|---|---|
| 138–152 (15 солов, все полные) | ≈ 56 К | 55,9 К (сырые 1–99 %: 56,0) | −0,1 К |
| 181–199 (17 солов, из них 4 неполных: 182, 184, 192, 194) | ≈ 87 К | 84,0 К по всем; 85,5 К по 13 полным (диапазон 84,6–86,9) | −1,5 К (полные), −3,0 К (все) |

Оговорки: числа статьи округлены («≈»), способ вычисления амплитуды (мин./макс. по сырым или усреднённым данным, по каким солам) в тексте не указан, поэтому это приближённое сравнение. Неполные сола (≈ 24–27 тыс. строк вместо ≈ 48 тыс.; ночной минимум приходится на час без данных) занижают амплитуду. **Результат по AC-49: на полных солах отклонение ≤ 1,5 К < 3 К — выполнено для амплитуды; абсолютные значения температуры по солам (рис. 3c, 5) не сверены — только по картинкам, оценка приблизительная, поэтому критерий закрывается «по амплитуде и по построению метода».**

Следствия: (1) метод и формула подтверждены источником; (2) в API помечать `estimate`/«яркостная температура, ε = 1», погрешность ≈ ±3 К днём; (3) неполные сутки (< ~40 тыс. строк) не использовать для min/max.

## 6. Конвенция направления ветра MEDA (для основной части)

SIS (`meda_env_rdr_sis`, Draft 01), поля `BOOM{1,2}_WIND_DIRECTION` и `WIND_DIRECTION`: «Wind direction **clockwise with respect to the north** in degrees». Единица в метке — `degree`. Отсчёт: по часовой стрелке от севера (север = 0°, восток = 90°) — подтверждено документом. **Откуда или куда дует** (from/to) SIS и метки `.xml` не говорят [не проверено]; в метеорологической конвенции «откуда», но для MEDA подтвердить можно только по статье/публикации (направление, скорее всего, определено по реконструкции на борту). Для `direction_mode_deg` предлагаю хранить значение как в источнике и описать в `API.md` как «азимут по часовой от севера, без утверждения from/to» до подтверждения.
