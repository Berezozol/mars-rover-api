For developers

Moving from the old API?

Change the host and keep your /mars-photos/api/v1/… calls. v1 mirrors the archived API’s responses.

GET /mars-photos/api/v1/rovers/curiosity/photos?sol=1000

API v2

All sample types, image sizes, real capture time and one error format. This site is built on v2 only.

GET /api/v2/rovers/perseverance/photos?sol=2031&camera=SUPERCAM_RMI
